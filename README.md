# Гаражная распродажа в Хуахине — Garage Sale by CJ

Одностраничный сайт для гаражной распродажи в Хуахине, Таиланд.  
Данные подтягиваются из Google Таблицы. Фото — из Google Диска.  
При изменении таблицы или добавлении фото сайт обновляется автоматически (каждые 5 минут или при открытии вкладки).

---

## Структура файлов

```
index.html              — разметка страницы
style.css               — стили
app.js                  — логика: загрузка данных, рендеринг, автообновление
config.js               — ВАШИ НАСТРОЙКИ (API ключ и т.д.)
photo-recognition.gs    — Google Apps Script для автораспознавания фото
README.md               — эта инструкция
```

## Первичная настройка (делается один раз)

### Шаг 1 — Опубликуйте Google Таблицу

1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1GxLJLYc5cToei0XRwlXvpcAxwycXcCMNnWgcRypen78/edit
2. **Файл → Поделиться → Опубликовать в интернете**
3. В первом выпадающем списке выберите **Sheet1** (или название вашего листа)
4. Во втором выпадающем списке выберите **Значения, разделённые запятыми (.csv)**
5. Нажмите **Опубликовать** → подтвердите в диалоге
6. Закройте окно (URL из окна не нужен)

> Таблица обновляется на сайте в течение нескольких секунд после сохранения изменений.

### Шаг 2 — Откройте доступ к папке Google Диска

1. Откройте папку: https://drive.google.com/drive/folders/1vduBNHsuhBdIzc2qFDtSwlNsawWTn-fC
2. Нажмите кнопку **Настройки доступа** (иконка человека со знаком +)
3. В разделе "Общий доступ" нажмите **Изменить** рядом с типом доступа
4. Выберите **Все, у кого есть ссылка** → уровень доступа **Читатель**
5. Нажмите **Готово**

### Шаг 3 — Получите API ключ Google (для Диска)

1. Откройте https://console.cloud.google.com/
2. Создайте новый проект или выберите существующий
3. В меню слева: **API и сервисы → Библиотека**
4. Найдите **"Google Drive API"** → нажмите **Включить**
5. Перейдите в **API и сервисы → Учётные данные**
6. Нажмите **+ Создать учётные данные → Ключ API**
7. Скопируйте ключ и вставьте в файл `config.js`:
   ```js
   GOOGLE_API_KEY: "AIzaSyXXXXXXXXXXXXXX",
   ```

**Ограничьте ключ** (рекомендуется для безопасности):
- Нажмите на созданный ключ → **Редактировать ключ API**
- **Ограничения для приложений**: HTTP-источники → добавьте домен вашего сайта (`https://YOURNAME.github.io/*`)
- **Ограничения API**: Google Drive API
- Нажмите **Сохранить**

### Шаг 4 — Настройте таблицу

Первая строка таблицы — заголовки (именно так):

| no | name | category | price | available_at | link_on_web |
|----|------|----------|-------|--------------|-------------|
| 1 | iPhone 13 Pro | `01 · Электроника` | 18000 | 25 апреля 2026 | https://www.lazada.co.th/... |
| 2 | Диван IKEA | `03 · Мебель` | 6000 | 25 апреля 2026 | https://shopee.co.th/... |

- **no** — порядковый номер товара (целое число)
- **name** — название товара
- **category** — код из таблицы выше (например, `01 · Электроника`)
- **price** — цена в батах; рекомендуемая формула: `=ROUND(рыночная_цена*0.75,-2)`
- **available_at** — дата доступности (оставьте пустым → будет `25 апреля 2026`)
- **link_on_web** — ссылка на похожий товар на Lazada / Shopee / JD Central

### Шаг 5 — Настройте автораспознавание фото

> Просто загружайте фото в папку Диска в любом виде — скрипт сам определит товар и переименует файл.

**5.1 — Получите бесплатный Gemini API ключ**
1. Откройте https://aistudio.google.com/app/apikey
2. Нажмите **Получить ключ API** (или **Create API key**)
3. Скопируйте ключ

**5.2 — Установите скрипт в Google Таблицу**
1. Откройте Google Таблицу
2. В верхнем меню: **Расширения → Apps Script**
3. Удалите весь существующий код в редакторе
4. Скопируйте полный код из файла `photo-recognition.gs` и вставьте
5. В начале скрипта вставьте ваш Gemini ключ:
   ```js
   var GEMINI_API_KEY = "AIzaSyXXXXXXXXXXXXXX";
   ```
6. Нажмите **Сохранить** (Ctrl+S или иконка дискеты)

**5.3 — Первоначальная авторизация (подробно)**

**А — Выберите функцию**  
В редакторе Apps Script в верхней панели есть выпадающий список рядом с кнопкой ▶.  
Нажмите на список → выберите **`setupTrigger`**.

**Б — Нажмите Запустить**  
Нажмите кнопку **▶ Запустить**. Внизу появится полоска *"Подготовка к выполнению…"*

**В — "Требуется авторизация"**  
Google покажет диалог:
> *"Для работы этого проекта требуется ваше разрешение"*

Нажмите **Проверить разрешения**.

**Г — Выберите аккаунт**  
Откроется всплывающее окно со списком аккаунтов Google.  
Выберите **тот аккаунт, которому принадлежит таблица и папка Диска**.

**Д — "Google не подтвердил это приложение"**  
Google покажет экран с предупреждением — это нормально для личных скриптов.  
В **нижнем левом углу** нажмите ссылку **Дополнительные настройки**.  
Затем нажмите ссылку **Перейти к [название проекта] (небезопасно)**.

**Е — Разрешите доступ**  
Google покажет список необходимых разрешений:
- Просмотр и управление файлами на Google Диске
- Просмотр и управление таблицами Google

Нажмите **Разрешить**.

**Ж — Выполнение завершено**  
Окно закроется. В панели **Журнал выполнения** (внизу редактора) появится:
```
Выполнение начато
Hourly триггер для autoRenamePhotos создан.
Выполнение завершено
```
В Google Таблице (правый нижний угол) появится уведомление:  
*"✅ Триггер создан: раз в час"*

**З — Проверьте триггер**  
В левой панели редактора Apps Script нажмите иконку **Триггеры** (часы).  
Должна быть строка:

| Функция | Источник | Тип | Интервал |
|---------|----------|-----|---------|
| autoRenamePhotos | Зависит от времени | Таймер по часам | Каждый час |

**5.4 — Запустите первое распознавание вручную**  
Вернитесь в Google Таблицу — в меню появился раздел **📸 Фото**.  
Нажмите **📸 Фото → "Распознать и переименовать новые фото"**.  
Результат будет виден в листе **"Photo Log"** таблицы.

#### Как работает распознавание

1. Скрипт находит в папке фото без правильного имени (не совпадающие с форматом `НН-ННН-*`)
2. Отправляет изображение в **Gemini 1.5 Flash** (бесплатная квота)
3. Gemini сопоставляет фото с товарами из таблицы
4. Файл переименовывается: `01-003-iphone-13-pro.jpg`
5. Результат записывается в лист **"Photo Log"**

```
01-003-iphone-13-pro.jpg
^^ ^^^ ^^^^^^^^^^^^^^^^
|  |   Название товара (транслит)
|  Номер товара (3 цифры)
Код категории (2 цифры)
```

> Если Gemini не смог определить товар — файл остаётся с исходным именем,  
> в Photo Log будет запись ❌ с пояснением причины.

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub (или используйте существующий)
2. Загрузите файлы `index.html`, `style.css`, `app.js`, `config.js`  
   *(файл `photo-recognition.gs` — только для Google Sheets, на сайт не нужен)*
3. Откройте **Settings → Pages**
4. Раздел **Build and deployment → Branch**: выберите ветку `main` → папка `/ (root)` → **Save**
5. Через 1-2 минуты сайт будет доступен по адресу:  
   `https://YOURNAME.github.io/REPO-NAME/`

## Решение проблем

### Сайт пишет "Failed to fetch" / "Не удалось загрузить данные"

**Причина**: Google Таблица не опубликована для публичного доступа.

**Решение**:
1. Откройте таблицу
2. **Файл → Поделиться → Опубликовать в интернете**
3. Выберите: лист **Sheet1** + формат **Значения, разделённые запятыми (.csv)**
4. Нажмите **Опубликовать** → подтвердите
5. Обновите страницу сайта (Ctrl+Shift+R)

---

### Лист "Photo Log" не появляется / файлы не переименовываются

**Шаг 1**: Убедитесь, что Gemini API ключ вставлен в скрипт:
```js
var GEMINI_API_KEY = "AIzaSy...ваш ключ...";
```

**Шаг 2**: Убедитесь, что в таблице есть товары (хотя бы одна строка с данными после заголовка).

**Шаг 3**: В Google Таблице нажмите **📸 Фото → "Распознать и переименовать новые фото"** и дождитесь завершения.

**Шаг 4**: После запуска лист "Photo Log" появится автоматически — там будут результаты или описание ошибки.

---

### GitHub Pages: предупреждение о custom domain

**Причина**: в настройках Pages заполнено поле "Custom domain" некорректным значением.

**Решение**:
1. Откройте **Settings → Pages** в репозитории GitHub
2. В разделе **Custom domain** очистите поле (удалите текст)
3. Нажмите **Save**
4. Предупреждение исчезнет

---

### Фото не загружаются на сайте

→ Убедитесь, что папка Диска открыта для всех (**Все, у кого есть ссылка — Читатель**)  
→ Проверьте API ключ Drive в `config.js`  
→ Откройте консоль браузера (F12 → Консоль) для деталей ошибки

---

### Сайт показывает старые данные

→ Нажмите Ctrl+Shift+R (жёсткое обновление) или подождите 5 минут
