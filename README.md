# Гаражная распродажа в Хуахине — Garage Sale by CJ

Одностраничный сайт для гаражной распродажи в Хуахине, Таиланд.  
Данные подтягиваются из Google Sheets. Фото — из Google Drive.  
При изменении таблицы или добавлении фото сайт обновляется автоматически (каждые 5 минут или при открытии вкладки).

---

## Структура файлов

```
index.html              — разметка страницы
style.css               — стили
app.js                  — логика: загрузка данных, рендеринг, автообновление
config.js               — ВАШИ НАСТРОЙКИ (API ключ и т.д.)
photo-recognition.gs    — Google Apps Script для автораспознавания фото
README.md               — эта инструкция
```

## Первичная настройка (делается один раз)

### Шаг 1 — Опубликуйте Google Таблицу

1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1GxLJLYc5cToei0XRwlXvpcAxwycXcCMNnWgcRypen78/edit
2. **File → Share → Publish to web**
3. Выберите: **Sheet1** и формат **Comma-separated values (.csv)**
4. Нажмите **Publish** → подтвердите
5. Закройте диалог (URL из диалога не нужен)

> Таблица обновляется на сайте в течение нескольких секунд после сохранения изменений.

### Шаг 2 — Откройте доступ к папке Google Drive

1. Откройте папку: https://drive.google.com/drive/folders/1vduBNHsuhBdIzc2qFDtSwlNsawWTn-fC
2. Нажмите **Share / Поделиться**
3. Измените доступ на **"Anyone with the link — Viewer"** (Все, у кого есть ссылка — Просмотр)
4. Сохраните

### Шаг 3 — Получите API ключ Google (для Drive)

1. Откройте https://console.cloud.google.com/
2. Создайте новый проект (или выберите существующий)
3. **APIs & Services → Library** → найдите **"Google Drive API"** → **Enable**
4. **APIs & Services → Credentials** → **"+ Create Credentials" → API key**
5. Скопируйте ключ и вставьте в `config.js`:
   ```js
   GOOGLE_API_KEY: "AIzaSyXXXXXXXXXXXXXX",
   ```

**Ограничьте ключ** (рекомендуется):
- Нажмите на ключ → **Edit API key**
- **Application restrictions**: HTTP referrers → домен вашего сайта (`https://YOURNAME.github.io/*`)
- **API restrictions**: Google Drive API

### Шаг 4 — Настройте таблицу

Первая строка таблицы — заголовки (именно так):

| no | name | category | price | available_at | link_on_web |
|----|------|----------|-------|--------------|-------------|
| 1 | iPhone 13 Pro | `01 · Электроника` | 18000 | 25 апреля 2026 | https://www.lazada.co.th/... |
| 2 | Диван IKEA | `03 · Мебель` | 6000 | 25 апреля 2026 | https://shopee.co.th/... |

- **no** — порядковый номер товара (целое число)
- **name** — название товара
- **category** — код из таблицы выше (например, `01 · Электроника`)
- **price** — цена в батах; рекомендуемая формула: `=ROUND(рыночная_цена*0.75,-2)`
- **available_at** — дата доступности (оставьте пустым → будет `25 апреля 2026`)
- **link_on_web** — ссылка на похожий товар на Lazada / Shopee / JD Central

### Шаг 5 — Настройте автораспознавание фото

> Этот шаг нужен чтобы фотографии автоматически распознавались и привязывались к товарам.  
> Просто загружайте фото в папку Drive в любом виде — скрипт сам разберётся.

**5.1 — Получите бесплатный Gemini API ключ**
1. Откройте https://aistudio.google.com/app/apikey
2. Нажмите **"Create API key"**
3. Скопируйте ключ

**5.2 — Установите скрипт в Google Таблицу**
1. Откройте Google Таблицу
2. **Extensions (Расширения) → Apps Script**
3. Удалите весь существующий код в редакторе
4. Скопируйте полный код из файла `photo-recognition.gs` и вставьте
5. В начале скрипта укажите ваш Gemini ключ:
   ```js
   var GEMINI_API_KEY = "AIzaSyXXXXXXXXXXXXXX";
   ```
6. Нажмите **Сохранить** (Ctrl+S или иконка дискеты)

**5.3 — Запустите первоначальную авторизацию**
1. В выпадающем списке функций выберите `setupTrigger`
2. Нажмите **Run (▶)**
3. Разрешите доступ к Google Drive и Sheets (выберите свой аккаунт → Advanced → Allow)
4. После этого скрипт будет запускаться автоматически каждый час

**5.4 — Ручной запуск**
В Google Таблице появится меню **📸 Фото** → "Распознать и переименовать новые фото"

#### Как работает распознавание

1. Скрипт находит фото без правильного имени (`NN-NNN-*`)
2. Отправляет изображение в **Gemini 1.5 Flash** (бесплатная квота)
3. Gemini сопоставляет фото с товарами из таблицы
4. Файл переименовывается: `01-003-iphone-13-pro.jpg`
5. Результат записывается в лист **"Photo Log"**

```
01-003-iphone-13-pro.jpg
^^ ^^^ ^^^^^^^^^^^^^^^^
|  |   Название товара
|  Номер товара (3 цифры)
Код категории (2 цифры)
```

> Если Gemini не смог определить товар по фото — файл остаётся с исходным именем,  
> а в Photo Log будет отметка ❌ с пояснением.

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub (или используйте существующий)
2. Загрузите файлы `index.html`, `style.css`, `app.js`, `config.js`  
   (файл `photo-recognition.gs` — только для Google Sheets, не нужен на сайте)
3. **Settings → Pages**
4. **Source**: "Deploy from a branch" → ветка `main` → папка `/ (root)` → **Save**
5. Через 1-2 минуты сайт доступен по адресу:  
   `https://YOURNAME.github.io/REPO-NAME/`

## Частые вопросы

**Фото не загружаются на сайте**  
→ Убедитесь, что папка Drive открыта для всех ("Anyone with link")  
→ Проверьте API ключ в `config.js`  
→ Откройте консоль браузера (F12 → Console) для деталей ошибки

**Скрипт распознавания не запускается**  
→ Проверьте что `GEMINI_API_KEY` указан в начале `photo-recognition.gs`  
→ Запустите `setupTrigger` ещё раз и повторно авторизуйте

**Товары не появляются**  
→ Убедитесь, что таблица опубликована (File → Publish to web → CSV)  
→ Проверьте заголовки первой строки: `no, name, category, price, available_at, link_on_web`

**Сайт показывает старые данные**  
→ Нажмите Ctrl+Shift+R (жёсткое обновление) или подождите 5 минут

**Нужна другая валюта**  
→ Отредактируйте `config.js` → `CURRENCY_SYMBOL`
